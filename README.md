## 📖 عن المشروع

هذا المشروع هو **ملخص بصري شامل** لدورة **"تخطيط وتنظيم العمل"** المقدمة من **معهد الإدارة العامة**، تم تصميمه بطريقة عصرية وبصرية لتسهيل المراجعة والاستيعاب للمتدربين والمهتمين بمجال الإدارة.

## 📚 المحاور الخمسة للدورة

| # | المحور | الصفحات | المواضيع الرئيسية |
|---|--------|---------|-------------------|
| 1 | **الإدارة والتنظيم** | 2–7 | مفهوم الإدارة، الكفاءة والفاعلية، مستويات الإدارة، تنظيم العمل، مبادئ التنظيم، خطوات التنظيم |
| 2 | **الوقت والأولويات والتفويض** | 8–11 | إدارة الوقت، مضيعات الوقت، قاعدة 80/20، مصفوفة الأولويات، التفويض |
| 3 | **التخطيط والأهداف الذكية** | 12–15 | مفهوم التخطيط، أنواع التخطيط، نموذج SWOT، معايير SMART |
| 4 | **مؤشرات الأداء KPIs** | 16–17 | مفهوم KPIs، أنواع المؤشرات، مواصفات المؤشر الجيد، بطاقة المؤشر |
| 5 | **الخطة التشغيلية** | 18–19 | مفهوم الخطة التشغيلية، مكوناتها، الهدف منها، مصفوفة المبادرات |

## 🚀 طريقة التشغيل

### 1. تحميل المشروع

```bash
git clone https://github.com/your-username/planning-and-organizing-summary.git
cd planning-and-organizing-summary
```

### 2. فتح الملف

افتح ملف `index.html` مباشرة في أي متصفح حديث:

```bash
# على Windows
start index.html

# على macOS
open index.html

# على Linux
xdg-open index.html
```

### 3. طباعة كـ PDF

1. افتح الملف في المتصفح
2. اضغط `Ctrl + P` (أو `Cmd + P` على macOS)
3. اختر **"حفظ كـ PDF"**
4. اضبط الإعدادات:
   - التخطيط: **عمودي**
   - الهوامش: **افتراضي**
   - خيارات متقدمة: **رسومات الخلفية** ✅ (تفعيلها)
